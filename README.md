# Nexora 📚

**Nexora** is a modern Android learning and note-management application designed to help students organize their lessons, notes, subjects, and study materials in one place.

## ✨ Features

* 📝 Create and edit notes
* 📚 Organize notes by subjects
* 📎 Add multiple attachments to a lesson
* 📄 Support for PDFs and other documents
* 🖼️ Add images and screenshots
* 🔗 Store links and code snippets
* 🔍 Search notes quickly
* ⭐ Favorite important lessons
* 📌 Pin important notes
* 🏷️ Add tags to notes
* 🕐 View recent lessons
* 🌙 Light and dark mode
* 📱 Home-screen widget
* 💾 Local/offline note storage
* 🎨 Modern Hazel/Brown themed interface
* 📂 Organized file attachments

## 🚀 Installation

### Option 1 — Download the APK

Go to the **Releases** section of this repository and download the latest APK.

1. Download the `.apk` file.
2. Open the APK on your Android device.
3. Allow installation from the required source if Android asks.
4. Install Nexora.
5. Open the application.

### Option 2 — Build from Source

Clone the repository:

```bash
git clone https://github.com/spark-ioz/Nexora.git
```

Open the project in **Android Studio**.

Allow Gradle to sync and then select:

**Build → Build Bundle(s) / APK(s) → Build APK(s)**

The generated APK can be found under:

```text
app/build/outputs/apk/
```

Nexora is designed to store notes and attachments locally on the device.

No account is required to use the basic note-taking functionality.
